# 中文学术排版偏好

用户明确要求使用本套规范或其中某条规则时，才应用相应设置。否则保留用户当前手动调整的格式；学校模板和用户最新要求优先。

## 文字、字体与段落换行

- 中文与英文字母、数字之间不输入空格。必要时关闭Word的“自动调整中文与西文的间距”和“自动调整中文与数字的间距”；仅删除可见空格，不一定能消除显示出的间距。
- 保留**英文句子内部**的空格，以及物理量数值与单位之间的空格，除非用户指定了其他单位格式。不要全局删除所有半角空格。
- 图题注是例外：采用`图 1 题注文字`，**标签与编号之间、编号与题注文字之间各保留一个半角空格**。正文交叉引用仅显示`图 1`，例如`如图 1所示。`，不得被中英文间距清理误删空格。表题注是否沿用同样格式，以用户或学校模板要求为准。
- 图题注字号为**四号（14 pt）**，中文使用宋体，英文字母和数字使用Times New Roman。将ASCII、high-ANSI和复杂文字字体属性设为Times New Roman，东亚字体属性设为宋体；仅在目标题注文字片段中清除与此冲突的主题字体设置。正文交叉引用的字号与所在正文一致，不继承题注字号。
- 希腊字母`μ`使用Times New Roman。定位并设置实际符号所在文字片段，不能想当然地认为东亚字体设置只会影响中文。不要把`μ`替换成`u`，也不要通过普通文本替换修改MathType对象内部内容。
- 用户要求段落之间空行时，使用实际的段落换行或空段落，不使用“段后一行”来模拟。避免反复添加多余空段落，同时保留其他位置有意设置的行距和分页约束。
- 按此偏好使用“采用”，不使用“借鉴”，但必须保留必要的文献引用和来源说明。这只是措辞调整，不表示可以把其他论文的设计写成自己的原创。

## 公式

- 用户明确要求时，使用可编辑的MathType对象。段内公式采用内联形式，公式OLE对象与前后文字之间不添加用于填充的空格。
- 段间公式独立排版，编号右对齐。用户要求时，采用连续整数编号，不使用`(6a)`、`(6b)`。原来挤在同一条段间公式中的不同关系式，应按用户要求拆开。
- 公式前不加冒号。该规则用于公式引导语，不是删除全文所有冒号。
- 保留公式基线、编号域、书签、单位字体和符号定义。修改正文字体时，不得损坏MathType预览或公式对象。
- 按参考文档简化理论时，优先保留其核心关系和常规符号，不增添复杂、多层下标。核查全篇符号定义，避免同一非通用符号用于不同物理量。

## 参考文献与图件

- 参考文献使用Word原生编号列表`[1]`、`[2]`、`[3]`；所选引文格式要求顺序编码时，按首次引用顺序排列。
- 正文文献引用使用指向编号项的Word原生REF域，并保留原来采用的上标或非上标格式。
- 正文对原生图题注的交叉引用仅包含“标签＋编号”，需要时带超链接；不把整段题注文字插入正文引用。
- 用户要求时，将流程图引导句放在每个研究方法分项正文的开头，不放入标题，也不在段尾再重复。

## 可选的辅助命令

```powershell
python scripts/docx_ops.py normalize source.docx --output normalized.docx --boundary-spaces --real-blank-lines --caption-fonts --caption-size 14 --adopt-wording
```

**仅选择用户已授权的选项**，不必每次全部启用：

- `--boundary-spaces`：清理中文与英文字母、数字之间的空格，并关闭相应自动间距设置。
- `--real-blank-lines`：把整行计量的`afterLines`段后间距转换为实际空段落；遇到非整数行时拒绝处理。它不会自行解释任意磅值的段后间距。
- `--caption-fonts`：调整简单`图N `或`图 N `题注的中英文字体；`--caption-size 14`单独指定四号字号。此命令保留原有标签间距，不重建已有书签；不覆盖所有题注样式。
- `--adopt-wording`：将“借鉴”改为“采用”。

段内公式对象旁的填充空格、符号所在片段的字体、段间公式拆分和重编号，以及表格修复，仍需在此辅助命令之外进行定点修改与视觉检查。
